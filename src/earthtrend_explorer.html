Plain English

Example finding · not a scientific result

In this illustrative example, the Amazon Basin is shown with a downward water-storage trend. Real NASA data and statistical tests are needed before drawing a conclusion.

Limitations to include

  • Demo values are placeholders, not observed NASA results.
  • Regional averages may hide local differences.
  • Correlation alone cannot establish a cause.
  • Study period and data quality influence the result.

🧭 Methodology & data

How the full version should make findings trustworthy.

Transparency
  1. Choose an authoritative dataset. For terrestrial water storage, investigate NASA GRACE/GRACE-FO products; for vegetation, MODIS products may be suitable. Confirm variable, units, coverage, and usage terms.
  2. Prepare the data. Align timestamps, handle missing observations, document spatial resolution, and aggregate to the chosen region or grid.
  3. Estimate the trend. Fit a defined trend model and report the slope with units and confidence intervals.
  4. Test significance. Account for serial correlation and multiple comparisons across map cells; show “not enough evidence” where appropriate.
  5. Find opposite trends. Match regions with opposite, sufficiently supported slopes and show the same time window wherever possible.
  6. Investigate possible drivers. Report correlation, lag choices, sample size, and uncertainty. Describe this as evidence, not proof of causation.
  7. Precompute results. Process data before the demo and serve validated files to the website for speed and reliability.
NASA data source note: this prototype is not connected to NASA APIs or datasets. Add verified source files, citations, and reproducible processing before presenting any numerical output as fact.
