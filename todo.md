Must have (the core project)
Variable picker: start with temperature only, with a one-line plain definition. This answers what is changing.
Place picker and map: choose a state or a city and click it on the map, using your State and City GeoJSON. This answers where.
Time-series chart: monthly values over a long record, with the seasonal cycle removed.
Trend result: slope in °C per decade, with the method named. This answers how much.
Significance badge: p-value, 95% confidence interval, and a plain “significant / not significant” label. This answers is it significant.
About and method panel: data source (MERRA-2), units, limits, and a clear demo-data label while the data is still short.
Should have
Trend map: states or grid cells colored by slope, with dots on the significant ones.
Zone averages: compare regions side by side.
